Privacy policy

Effective date: 10 November 2026. Operator: Anton Babaev.

This policy covers the owner's deployment OAuth client, INFAPRIM GitHub Automation. It does not describe the public calendar application's separate processing of event data.

Google data and purpose

The delivery workflow processes source files, manifests, project metadata and numbered versions of the explicitly configured Apps Script TEST project to upload and verify the owner's code. The requested scope is script.projects. It technically authorizes access to the owner's accessible script projects; workflow guards restrict the target.

This deployment client does not request Gmail messages, Sheets records, Calendar events, photographs or Telegram data. Runtime permissions of the deployed application are separate. Delivery code is used for code delivery and verification only, not advertising, sale or training generalized AI models by this automation.

Processing and storage

Google handles OAuth authorization and Apps Script project storage. GitHub stores the private application repository, encrypted Actions environment secrets and execution metadata. A hosted GitHub runner temporarily processes source and access tokens to upload and verify code. Client secrets and refresh tokens are stored in GitHub Actions Secrets after entry by the owner. Credentials must not be committed or included in logs or artifacts.

Source history remains in the owner's private repository and Apps Script versions until removed using supported platform controls. Workflow logs and result metadata follow repository retention settings. Runner-local credentials are temporary and must not be uploaded as artifacts.

Owner controls and deletion

The owner may revoke authorization in Google Account connections, delete the GitHub OAuth secrets, disable delivery workflows and remove retained artifacts. Revocation stops future authorized API calls but does not automatically delete existing source history, script versions or logs. Questions and deletion requests can be submitted through the operator contact link below; never post credentials or private event data.

Security and platform processing

Credential access is limited to the owner and authorized repository administrators. Administrators able to modify secret-consuming workflows can affect credential security. Google and GitHub process technical request information under their respective policies. This information site uses GitHub Pages and has no application-level advertising or analytics scripts.

This automation's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements where applicable.
