INFAPRIM GitHub Automation

Owner-operated code delivery for the INFAPRIM calendar project. Operator: Anton Babaev.

Purpose

This OAuth client lets the owner authorize GitHub Actions to read, update and verify Google Apps Script source code and numbered versions. It is a deployment tool for the owner, not a sign-in service for calendar visitors.

Initial setup targets a separate TEST script. Updating the working calendar requires separate owner approval. This site does not contain application source, credentials or event records.

Authorization

The delivery client requests Google Apps Script project access (script.projects). The OAuth scope can access the author's accessible script projects; the delivery workflow restricts its configured target. Calendar runtime permissions are separate from deployment authorization.

Automation setup is in progress. This informational site does not claim a completed release or working unattended connection.
